## Актуальний план

- [Product Roadmap v2](./roadmap-v2.md) — **єдине активне джерело пріоритетів і
  порядку наступних робіт**.

  plan із технічними рішеннями, підетапами й Definition of done.

Якщо старі специфікації, README або архівний план суперечать roadmap щодо того,
**що робити наступним або що входить у реліз**, пріоритет має Product Roadmap v2.
